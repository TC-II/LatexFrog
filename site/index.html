Features

Everything a long document needs.

Profiles and partial builds

Build the whole book, the chapter you are in, or any set of parts. Page and equation numbers match the full PDF.

Figure cache

Heavy TikZ and PGFPlots compile once. A check shows which figures changed, and only those rebuild.

Instant SyncTeX

Click the PDF and land on the exact word. Click the source and the PDF follows, in the visual editor too.

Visual and source editor

Write in the page, or in code. Equations, figures and citations show as they print. LaTeX, Typst and Markdown.

Exports that match print

Export parts as their own PDFs with the numbering they have in the book, from a delivery profile, never with draft images.

Project diagnostics

A doctor for the project, orphan files, a project lock, build history, and a problems panel that points at the line.

Any LaTeX folder

Open a folder from Overleaf, a Git repository or a course. LatexFrog finds the main file, the parts and the headings.

Comments and collaboration

Comments, suggestions, Git, and real-time editing with the people you write with.

An agent in the editor

Bring your own AI agent to a panel beside the document, with the project as its context.

Under the hood

One engine, one build path.

The app never shells out to a compiler on its own. Every compile, preview and lookup goes through a sidecar process written in Rust.

The appElectron and Svelte. Visual and source editors, PDF viewer.
→
lv-sidecarJSON lines over standard input and output. Cancels cleanly.
→
lv-coreProject graph, profiles, figure cache, SyncTeX, diagnostics.
→
Your TeXMiKTeX or TeX Live, with latexmk. Nothing to bundle.
Get started

Install it and open a folder.

Download the Windows installer, run it, and open your LaTeX project. You also need a TeX distribution, MiKTeX or TeX Live, if you have none.

Download for Windows Get MiKTeX Get TeX Live

The installer is not code-signed yet: if Windows SmartScreen warns, choose More info, then Run anyway. Linux builds will follow.

Or build it yourself

You need Node, Rust and a TeX distribution.

# the app
npx --yes pnpm@10.14.0 install --config.engine-strict=false
pnpm app:build
pnpm exec electron-builder --dir

# the engine
cargo build --release -p lv-sidecar
