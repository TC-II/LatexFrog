A course of exercise guides with the `subfiles` package. `main.tex` brings every guide with `\subfile`, and each guide's `main.tex` also compiles on its own. The class and a package live in `style/`, which only the `latexmkrc` puts on TeX's path. Inside a guide, paths are relative to the guide's folder (`\input{exercise-list}`, `exercises/<slug>`, `figures/`). `\exercise{slug}`, defined in the class, opens an untitled `\subsection`, sets the label `ex:<slug>` and inputs the exercise; `\example{slug}`, defined in the package, inputs a worked example.
