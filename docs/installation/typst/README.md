# Typst

## From LatexFrog (recommended)

1. Open any folder with a .typ file.
2. Open the .typ file.
3. Click **Set Up Typst** in the bar above it.

## Install Typst yourself

On [Windows](windows.md), [macOS](macos.md), or [Linux](linux.md).
